# Conclusion & Next Steps
##### [Table of Contents](../README.md) | [Previous Page](04-quality-and-tradeoffs.md)
---
This analysis focused on understanding vendor activity, contract distributions, and data reliability within a large and imperfect dataset.

From a data perspective, this exercise reinforces that not all inconsistencies need to be resolved upfront. Instead, acknowledging limitations while continuing analysis allows for meaningful insights without over investing in data edge cases.

**Next Steps:**
If this analysis were to be extended, my focus would shift towards:
- **Improving data reliability**
    - Standardizing vendor names to reduce duplication.
    - Addressing null-heavy fields such as postal codes.
    - Investigating anomalous dates.
- **Deepening vendor analysis**
    - Identifying repeat vs one-time vendors.
    - Segmenting vendors by contract size and frequency.
    - Exploring long-term vendor relationships over time.
- **Expanding geographic insights**
    - Enhancing postal code coverage.
    - Mapping contract distribution across regions.
    - Identifying regional concentration or gaps in spending.
- **Temporal analysis**
    - Analyzing trends in contract value over time.
    - Identifying periods of increased procurement activity.
    - Exploring seasonality or policy-driven shifts.
- **Indigenous Considerations:**
    - Trends in Indigenous vendor participation and contract value.
    - Gaps in representation within overall procurement activity.
