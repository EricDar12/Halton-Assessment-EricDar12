# Submission Checklist

Include the items below in your submission.

---

## Repository

- Project uploaded to GitHub (share the repo link)
- All notebooks/code used for exploration and analysis included
- Any scripts or helper files included (if applicable)
- No raw dataset file committed (keep it local under `data/`)

---

## Work Artifacts

- Clear analysis notebook(s) showing:
  - how you explored the data
  - the queries/steps used to reach your conclusions
  - brief notes on assumptions and decisions
- Any outputs you generated included (optional but helpful):
  - small summary tables
  - charts/images
  - exported CSVs (small only)

---

## Presentation Deliverable

- Include your presentation/report deliverable file(s) **in the GitHub repository** (slides, PDF, markdown report, notebook report section, or other format)
- Ensure the deliverable is easy to find (e.g., in a `deliverables/` or `documents/` folder) and can be opened/reviewed without extra setup
- Confirm all notebooks and deliverables are present and working as expected before submitting

---
