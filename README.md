# Government of Canada Contract Analysis
*A data exploration project examining federal contract disclosures.*

---

## Project Overview:

This project explores publicly available **Government of Canada contract  data** to better understand patterns in federal procurement. 

The work focuses on three core objectives:

- Understanding the **structure and reliability of the dataset**
- Exploring **patterns in federal procurement spending**
- Communicating findings clearly through structured analysis

---

| Tool | Purpose |
